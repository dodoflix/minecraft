# The using_item trigger: fired every tick a player uses an item (bow draw, shield, spyglass, food), before the item use runs; the
# condition sees the player (sneaking), the item, and with a spyglass the entity looked at (vanilla spyglass_at_parrot: the parrot is on
# the ray of the eyes of one player, a pig on the ray of another). A bow without arrows is refused: the use never starts.
datapack adv_items
command_env
level flat
preload 2
difficulty normal
entity_counter 29600
level_seed 29601
spawn_player Bow survival 0.5 -60 0.5 0 0
spawn_player NoArrows survival 6.5 -60 0.5 0 0
spawn_player Shield survival 12.5 -60 0.5 0 0
spawn_player Glass survival 18.5 -60 0.5 0 0
spawn_player Sneak survival 24.5 -60 0.5 0 0
spawn_player Wrong survival 30.5 -60 0.5 0 0
give Bow mainhand minecraft:bow
give Bow hotbar1 minecraft:arrow 8
give NoArrows mainhand minecraft:bow
give Shield mainhand minecraft:shield
give Glass mainhand minecraft:spyglass
give Sneak mainhand minecraft:spyglass
give Wrong mainhand minecraft:spyglass
mobspawn Parrot minecraft:parrot 18.5 -59.2 6.5 0 0 nofinalize {PersistenceRequired:1b,NoAI:1b}
mobspawn Pig minecraft:pig 30.5 -60 6.5 0 0 nofinalize {PersistenceRequired:1b,NoAI:1b}
tick 3
dump advancements:Bow advancements:NoArrows advancements:Shield advancements:Glass advancements:Sneak advancements:Wrong
note a drawn bow, a bow without arrows, a raised shield, spyglasses
use Bow main 1
use NoArrows main 2
use Shield main 3
use Glass main 4
input Sneak sneak
tick 1
use Sneak main 5
use Wrong main 6
tick 3
dump advancements:Bow advancements:NoArrows advancements:Shield advancements:Glass advancements:Sneak advancements:Wrong use:Bow use:NoArrows use:Shield use:Glass use:Sneak use:Wrong
note the draw is released, the glass is still up
release Bow
release Shield
tick 2
dump advancements:Bow advancements:Shield use:Bow use:Shield inventory:Bow
