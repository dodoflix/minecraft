# Dispenser and sulfur cubes (DispenserBlock.getDefaultDispenseMethod -> SulfurCubeBlockDispenseItemBehavior for #sulfur_cube_swallowable items):
# the first sulfur cube in the block in front that accepts the item (SulfurCube.equipItem: an adult that does not already hold the same item)
# swallows one item into its body slot and plays the absorb sound; a held different item is spawned back out. Without a taker the item
# is dropped by the default behaviour. Equippable beats swallowable, so carved pumpkins are not tested here.
# Every dispense/spawn line is unique: the replay seeds the entity UUIDs and random from the command line.
level flat
preload 2
time 18000
note c1 a sulfur cube in front, a stack of 3 andesite: one is swallowed (absorb sound, body slot, entity_data of the cube)
block 0 -60 0 minecraft:dispenser[facing=east,triggered=false]
be_nbt 0 -60 0 {Items:[{Slot:0b,id:"minecraft:andesite",count:3}]}
spawn cube1 minecraft:sulfur_cube 1.5 -60 0.5 0 0 {NoAI:1b,Silent:1b}
level_seed 301
dispense 0 -60 0 c1
dump be:0,-60,0 entities events nbt:cube1
note c2 the same item again: the cube already holds andesite, equipItem is false and the item is dropped
dispense 0 -60 0 c2
dump be:0,-60,0 entities events nbt:cube1
