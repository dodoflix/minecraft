# EnderEyeItem on end portal frames. useOn fills an empty frame (push entities up, comparator update, level event 1503, the eye is
# consumed even in creative), the eye that completes the ring of twelve opens the portal (nine end_portal blocks, global level event
# 1038); a ring with a wrongly facing frame stays closed; a frame that already holds an eye passes, and use while looking at a frame
# passes too (nothing is launched).
level flat
preload 3
spawn_player A survival 0.5 -60 -2.5 0 0
spawn_player C creative 30.5 -60 8.5 0 0

note A: one frame with a comparator and a lamp behind it, an armor stand standing on top of the frame

use_on A 0 -60 0 up main
dump entities blocks:0,-60,0,2,-60,0 events packets:A:level_event inventory:A
