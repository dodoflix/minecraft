# The recipe book placing a recipe into the 2x2 grid of the player's own menu (ServerboundPlaceRecipe): items move from the
# inventory into the grid (one container_set_slot of the result slot per grid change), a recipe that cannot be made clears the
# grid and gets the ghost recipe packet, and the cases the listener ignores. Slots: 0 result, 1-4 grid, 9-35 inventory,
# 36-44 hotbar. Player A is the survival case, B creative, C a spectator, D has a full inventory (the grid cannot be cleared),
# E is creative with a full inventory (the grid is cleared by dropping it).
command_env
level flat
preload 2
spawn_player A survival 0.5 -60 3.5 180 0
spawn_player B creative 6.5 -60 3.5 180 0
spawn_player C spectator 12.5 -60 3.5 180 0
spawn_player D survival 18.5 -60 3.5 180 0
spawn_player E creative 24.5 -60 3.5 180 0
give A inv9 minecraft:oak_planks 64
give A inv10 minecraft:oak_log 8
give A inv11 minecraft:cobblestone 20
tick 2
cmd recipe give A minecraft:crafting_table
cmd recipe give A minecraft:oak_planks
cmd recipe give A minecraft:stick
cmd recipe give A minecraft:oak_button
cmd recipe give A minecraft:iron_ingot_from_iron_block
cmd recipe give A minecraft:iron_pickaxe
dump menu:A packets:A:container_set_slot,container_set_content,set_cursor_item,place_ghost_recipe recipes:A packets:B:none packets:C:none packets:D:none packets:E:none

note one set of ingredients; placing again grows the placed set by one each time, a recipe that matches the grid stops at the stack limit
place_recipe A minecraft:crafting_table
dump menu:A packets:A:container_set_slot,container_set_content,set_cursor_item,place_ghost_recipe
place_recipe A minecraft:crafting_table
place_recipe A minecraft:crafting_table
dump menu:A packets:A:container_set_slot,container_set_content,set_cursor_item,place_ghost_recipe
note use max items fills the grid with the most the inventory allows
place_recipe A minecraft:crafting_table all
dump menu:A packets:A:container_set_slot,container_set_content,set_cursor_item,place_ghost_recipe
note take the result: the placed stacks shrink, the result slot is recomputed for every mutation
