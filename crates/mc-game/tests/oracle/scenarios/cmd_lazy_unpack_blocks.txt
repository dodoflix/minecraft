# Commands that touch a block entity with a pending loot table: `data get block` and `clone` read the saved form (no unpack), slot access
# (`execute if items`, `item replace|modify`, `loot replace|insert`) unpacks before it reads or writes, `data merge` keeps ignoring Items
# while LootTable is present, `data remove LootTable` ends the pending state. A hopper stays locked by a redstone block so that its own tick
# does not unpack it. Crafters read and test slots without an unpack, so only a write unpacks them.
