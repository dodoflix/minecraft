# The saved form of the custom boss bars: the data file the storage writes for bars made by commands, the same bars through the codec and
# back (their players stay stored, nobody is sent anything), bars written by hand (defaults, every property, an invalid max, a hidden
# bar), and the bars a player gets when it joins afterwards. The loaded bars get fixed ids (vanilla draws random ones).
command_env
level flat
preload 2
level_seed 3301
entity_counter 3300
spawn_player A creative 0.5 -60 0.5 0 0
spawn_player B survival 4.5 -60 0.5 0 0
spawn_player C survival 8.5 -60 0.5 0 0
gamerule send_command_feedback false
tick 1
dump packets:A:none packets:B:none packets:C:none saved:custom_boss_events
note before any bar was made
level_seed 41
cmd bossbar add test:plain "Plain"
level_seed 42
cmd bossbar add test:full {"text":"Full","color":"gold","bold":true}
cmd bossbar set test:full color purple
cmd bossbar set test:full style notched_12
cmd bossbar set test:full max 80
cmd bossbar set test:full value 20
cmd bossbar set test:full players A B
cmd bossbar set test:full players @a
cmd bossbar set test:plain visible false
cmd bossbar set test:plain players C
dump bossbars saved:custom_boss_events packets:A:boss_event packets:B:boss_event packets:C:boss_event
note through the codec and back: the same bars, new ids, no packets
bossbars_load
dump bossbars saved:custom_boss_events packets:A:boss_event packets:B:boss_event packets:C:boss_event
cmd bossbar get test:full players
cmd bossbar set test:full value 21
cmd bossbar set test:plain visible true
dump bossbars packets:A:boss_event packets:B:boss_event packets:C:boss_event
note a player that joins afterwards gets the bars it is stored on, with the loaded ids
leave A
spawn_player A creative 0.5 -60 0.5 0 0 joinburst
dump packets:A:boss_event
leave C
spawn_player C survival 8.5 -60 0.5 0 0 joinburst
dump packets:C:boss_event
cmd bossbar get test:full players
cmd bossbar set test:full value 22
