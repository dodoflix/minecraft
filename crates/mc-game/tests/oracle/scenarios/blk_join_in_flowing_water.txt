# A simulated player that joins inside flowing water: the join teleport the client accepts moves the player once, which refreshes its fluid
# state before the first tick, so the stream pushes it from the first tick on.

fill 1 -60 4 12 -60 4 minecraft:stone

spawn_player Swept survival 3.5 -60 3.5 0 0 sim
watch player:Swept

watch off
