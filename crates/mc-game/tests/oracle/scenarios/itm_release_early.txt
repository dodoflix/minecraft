# Releasing the use key before an item is finished: nothing is consumed, no effect and no cooldown, the eating sounds up to that tick stay;
# the item can be used again from the start afterwards.
level flat
preload 2
spawn_player P survival 0.5 -60 0.5 0 0
give P hotbar0 minecraft:apple 3
