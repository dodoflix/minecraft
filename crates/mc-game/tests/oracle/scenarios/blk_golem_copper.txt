# Copper golem pattern: a carved pumpkin or jack o'lantern on a block of the copper tag builds a copper golem (state from the
# block's weathering, waxed blocks as their unwaxed stage) and the block becomes a chest of that stage facing like the head.
level flat
preload 6
level_seed 555
spawn_player Steve survival 0.5 -60 4.5 0 0
give Steve hotbar0 minecraft:carved_pumpkin 16
give Steve hotbar1 minecraft:jack_o_lantern 16
select Steve 0
note the eight blocks of the copper tag, the player faces every way
block 0 -60 0 minecraft:copper_block
use_on Steve 0 -60 0 up main 0.5 1.0 0.5
snap Steve 4.5 -60 4.5 90 0
block 4 -60 0 minecraft:exposed_copper

block 8 -60 0 minecraft:weathered_copper

block 12 -60 0 minecraft:oxidized_copper

select Steve 1
snap Steve 16.5 -60 4.5 0 0
block 16 -60 0 minecraft:waxed_copper_block
