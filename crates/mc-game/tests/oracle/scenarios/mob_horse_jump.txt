# The jump of a ridden horse: the charged jump of the player command (power 100 and a short one) from START_RIDING_JUMP to
# STOP_RIDING_JUMP, the rearing and standing timers, the movement packets of the rider, the jump sound and fall damage of a horse that
# lands, and the jump of a horse led by a leash.
level flat
difficulty normal
preload 4
entity_counter 1000
level_seed 1001
spawn_player Steve survival 0.5 -60 0.5 0 0
mobspawn H minecraft:horse 3.5 -60 0.5 0 0 nofinalize {PersistenceRequired:1b,Tame:1b,equipment:{saddle:{id:"minecraft:saddle",count:1}},attributes:[{id:"minecraft:jump_strength",base:0.7d},{id:"minecraft:movement_speed",base:0.225d}]}
entity_seed H 31
tick 30
ride Steve H
accept_teleport Steve
tick 2
dump mob:H edata:H player:Steve events
note a full charge: the jump starts with the release, rearing off, sound and game event
pcommand Steve START_RIDING_JUMP 100
tick 1
dump mob:H edata:H
pcommand Steve STOP_RIDING_JUMP
watch mob:H events
tick 4
watch off
note the client moves the horse up and back down; the server keeps the flags
move_vehicle Steve 3.5 -59.2 0.5 0 0 false
move_vehicle Steve 3.5 -59.5 0.5 0 0 false
move_vehicle Steve 3.5 -60.0 0.5 0 0 true
tick 3
dump mob:H edata:H events
note a short charge
pcommand Steve START_RIDING_JUMP 30
tick 3
pcommand Steve STOP_RIDING_JUMP
dump mob:H edata:H events
tick 5
dump mob:H edata:H events
note a fall onto the horse: its fall damage is reduced by 3 and its attribute multiplier
velocity H 0 0 0
tp H 3.5 -48 0.5
tick 30
dump mob:H player:Steve events
