# Item frames and commands: `/item replace` and `/item modify` on the slot contents (a frame has the single slot 0: the stored
# stack keeps one item, the add-item sound plays, a comparator behind the frame is updated), slots a frame does not have, the
# copy between a frame, an item entity and a player, and the frame in command feedback.
command_env
level flat
preload 3
level_seed 5
entity_counter 920
spawn_player A creative 6.5 -60 4.5 90 0
op A
block 3 -60 0 minecraft:stone
block 3 -60 2 minecraft:stone
block 3 -60 4 minecraft:stone
block 3 -60 6 minecraft:stone
tick 2
dump packets:A:none
spawn f1 minecraft:item_frame 4.5 -59.5 0.5 0 0 {Facing:5b,Tags:[one]}
entity_seed f1 31
spawn f2 minecraft:glow_item_frame 4.5 -59.5 2.5 0 0 {Facing:5b,Tags:[two],Item:{id:"minecraft:diamond_sword",count:1,components:{"minecraft:custom_name":"Blade"}},ItemRotation:3b}
entity_seed f2 32
spawn f3 minecraft:item_frame 4.5 -59.5 4.5 0 0 {Facing:5b,Tags:[three],Item:{id:"minecraft:stick",count:1}}
entity_seed f3 33
spawn i1 minecraft:item 6.5 -60 6.5 0 0 {Item:{id:"minecraft:emerald",count:5},Tags:[four],PickupDelay:32767s}
entity_seed i1 34
tick 2
dump xentities edata:f1 edata:f2 packets:A:none events
note names in feedback and data get
cmd execute as A run data get entity @e[type=item_frame,tag=two,limit=1] Item
cmd execute as A run tag @e[type=item_frame,limit=1,sort=nearest] list
cmd execute as A run effect give @e[type=item_frame,tag=one] minecraft:speed
note replace the contents of an empty frame
cmd execute as A run item replace entity @e[type=item_frame,tag=one,limit=1] contents with minecraft:apple 4
tick 1
dump xentity:f1 edata:f1 nbt:f1 packets:A:set_entity_data events
note slots a frame does not have
cmd execute as A run item replace entity @e[type=item_frame,tag=one,limit=1] contents.0 with minecraft:emerald 4
cmd execute as A run item replace entity @e[type=item_frame,tag=one,limit=1] weapon.mainhand with minecraft:emerald 4
cmd execute as A run item replace entity @e[type=item_frame,tag=one,limit=1] container.0 with minecraft:emerald 4
cmd execute as A run item replace entity @e[type=item_frame,tag=one,limit=1] armor.head with minecraft:iron_helmet
tick 1
dump xentity:f1 nbt:f1 packets:A:set_entity_data events

cmd execute as A run item modify entity @e[type=item_frame,tag=two,limit=1] contents {type:"minecraft:set_count",count:9}

cmd execute as A run item modify entity @e[type=item_frame,tag=three,limit=1] contents {type:"minecraft:set_damage",damage:0.5}

dump xentities edata:f2 edata:f3 nbt:f2 nbt:f3 packets:A:set_entity_data events

cmd execute as A run item replace entity @e[type=item,tag=four,limit=1] contents from entity @e[type=item_frame,tag=one,limit=1] contents

cmd execute as A run item replace entity @e[type=item_frame,tag=one,limit=1] contents from entity A weapon.mainhand
