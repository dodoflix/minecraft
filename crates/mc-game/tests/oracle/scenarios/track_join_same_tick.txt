# An entity that exists when a player joins is not tracked by that player in the same tick, nor later while neither of them moves: the chunks of the
# joining player are pending, and the pairing is only re-evaluated when the player moves or the entity changes its section.
command_env
level flat
preload 3
difficulty peaceful
entity_counter 100
level_seed 7
spawn cow minecraft:cow 4.5 -60 2.5 45 0 {NoAI:1b,Silent:1b,PersistenceRequired:1b}
spawn pig minecraft:pig 2.5 -60 4.5 45 0 {NoAI:1b,Silent:1b,PersistenceRequired:1b}
entity_seed cow 9
entity_seed pig 8
spawn_player A survival 6.5 -60 4.5 0 0
spawn_player B survival 6.5 -60 8.5 0 0
tick 1
dump packets:A:add_entity,remove_entities packets:B:add_entity,remove_entities
tick 3
dump packets:A:add_entity,remove_entities packets:B:add_entity,remove_entities
note the player moves: its pairing is re-evaluated
move_packet A 6.7 -60 4.5 true
tick 1
dump packets:A:add_entity,remove_entities packets:B:add_entity,remove_entities
note a new entity is tracked at once
spawn sheep minecraft:sheep 5.5 -60 5.5 0 0 {NoAI:1b,Silent:1b,PersistenceRequired:1b}
tick 2
dump packets:A:add_entity,remove_entities packets:B:add_entity,remove_entities
