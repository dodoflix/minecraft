# `/reload` with a real data pack that changes between reloads: an edited function, a new one, a removed one, a function that stops
# parsing and one that is fixed again, edited load and tick tags (the load tag runs once per reload, before the tick tag), tags that
# reference functions that appear later, scheduled events across a reload, the feedback and the logs of every reload.
datapack fnpack
command_env
level flat
preload 2
entity_counter 4000
spawn_player A survival 0.5 -60 0.5 0 0
tick 1
dump packets:A:none
gamerule send_command_feedback true
dump logs
note the library as loaded
cmd function fn:hello
cmd function fn:fresh
dump storage:fn:state
note an edited function is read at the next reload only
pack_file fnpack data/fn/function/hello.mcfunction data modify storage fn:state hello set value 2b\nsay hello-edited
cmd function fn:hello
dump storage:fn:state
cmd reload
tick 1
cmd function fn:hello
dump storage:fn:state
dump logs
note new functions, tags and predicates appear
pack_file fnpack data/fn/function/fresh.mcfunction data modify storage fn:state fresh set value 1b\nreturn 11
pack_file fnpack data/fn/tags/function/fresh_tag.json {"values":["fn:fresh","fn:hello"]}
pack_file fnpack data/fn/predicate/fresh.json {"type":"minecraft:all_of","terms":[]}
cmd function fn:fresh
cmd function #fn:fresh_tag
cmd execute if predicate fn:fresh
cmd reload
tick 1
cmd function fn:fresh
cmd execute store result score #r fn run function fn:fresh
cmd scoreboard players get #r fn
cmd function #fn:fresh_tag
cmd execute if predicate fn:fresh
dump storage:fn:state
note a removed function and a tag that lost its function
pack_remove fnpack data/fn/function/fresh.mcfunction
cmd function fn:fresh
cmd reload
tick 1
cmd function fn:fresh
cmd function #fn:fresh_tag
dump logs
note a tag that names a function that does not exist yet fails to load as a whole, and loads when the function appears
pack_file fnpack data/fn/tags/function/late.json {"values":["fn:late_a","fn:late_b"]}
pack_file fnpack data/fn/function/late_a.mcfunction say late-a
cmd reload

cmd function #fn:late
dump logs
pack_file fnpack data/fn/function/late_b.mcfunction say late-b
cmd reload
tick 1
cmd function #fn:late
dump logs

cmd reload

dump logs
cmd function #fn:fresh_tag

cmd reload

cmd function fn:hello
