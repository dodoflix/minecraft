# The inventory screen of tamed nautilus: a saddle slot and an armor slot and no chest slots. Opening it by sneaking or from the
# saddle, what each slot accepts, shift-click in both directions, the screen of a wild or baby one (none), the equipment the nautilus
# keeps, the zombie nautilus alike, and the screen closing when the nautilus is out of reach or gone.
command_env
level flat
preload 4
spawn_player A survival 0.5 -60 6.5 180 0
spawn_player S spectator 12.5 -60 6.5 180 0
entity_counter 100
spawn N minecraft:nautilus 0.5 -60 4.5 0 0 {NoAI:1b}
spawn Z minecraft:zombie_nautilus 3.5 -60 6.5 0 0 {NoAI:1b}
spawn U minecraft:nautilus 7.5 -60 6.5 0 0 {NoAI:1b}
spawn B minecraft:nautilus 4.5 -60 9.5 0 0 {NoAI:1b,Age:-24000}
tame N A
tame Z A
tame B A
give A hotbar0 minecraft:saddle
give A hotbar1 minecraft:iron_nautilus_armor
give A hotbar2 minecraft:white_carpet 3
give A hotbar3 minecraft:stick 5
give A hotbar4 minecraft:bread 20
give A inv9 minecraft:saddle
give A inv10 minecraft:copper_nautilus_armor
give A inv11 minecraft:apple 30
give S hotbar0 minecraft:saddle
tick 1
dump packets:A:none packets:S:none
note sneaking at a tamed nautilus opens its screen: the screen packet with the mount entity and the content with the saddle and armor slots
interact A N main sneak
dump menu:A packets:A:mount_screen_open,open_screen,container_set_content
note the saddle slot takes a saddle only and one item, the armor slot takes nautilus armor only
click A 29 0 PICKUP
click A 0 0 PICKUP
click A 1 0 PICKUP

click A 0 0 PICKUP
click A 30 0 PICKUP
click A 1 0 PICKUP

click A 30 0 PICKUP
click A 31 0 PICKUP
click A 1 0 PICKUP
