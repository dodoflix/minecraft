# any_block_use sees the in-hand object of a use that kills the player: a charged respawn anchor explodes outside the nether and the stick in
# the hand goes into the death drops intact (a match); with keep_inventory the stick stays in the hand (a match as well).
datapack adv_use
command_env
level flat
preload 4
difficulty normal
entity_counter 31300
level_seed 31301
spawn_player A survival 0.5 -60 2.5 0 0
spawn_player B survival 40.5 -60 2.5 0 0
block 0 -60 0 minecraft:respawn_anchor[charges=2]
block 40 -60 0 minecraft:respawn_anchor[charges=2]
tick 5
dump advancements:A advancements:B
note the stack in the hand of a player who dies of the explosion
give A hotbar0 minecraft:stick 3
select A 0
snap A 0.5 -60 2.5
tick 1
use_on A 0 -60 0 up main
dump advancements:A player:A inventory:A
tick 2
dump advancements:A entities
note keep_inventory: the stick stays in the hand
gamerule keep_inventory true
give B hotbar0 minecraft:stick 3
select B 0
snap B 40.5 -60 2.5
tick 1
use_on B 40 -60 0 up main
dump advancements:B player:B inventory:B
